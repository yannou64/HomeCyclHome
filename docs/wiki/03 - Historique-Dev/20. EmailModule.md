## Concept

Le module email gère l'envoi de mails transactionnels via **Nodemailer**, intégré à NestJS via le wrapper `@nestjs-modules/mailer`. En développement, les emails sont interceptés par **Mailpit** (faux serveur SMTP local) — aucun vrai email n'est envoyé.

---

## Installation

```bash
npm install @nestjs-modules/mailer nodemailer
npm install -D @types/nodemailer
```

---

## email.module.ts

```typescript
import { Module } from '@nestjs/common';
import { MailerModule } from '@nestjs-modules/mailer';
import { EmailService } from './email.service';

@Module({
    imports: [
        MailerModule.forRoot({
            transport: {
                host: process.env.MAIL_HOST,
                port: Number(process.env.MAIL_PORT),
                auth: {
                    user: process.env.MAIL_USER,
                    pass: process.env.MAIL_PASS,
                },
            },
            defaults: {
                from: process.env.MAIL_FROM,
            },
        }),
    ],
    providers: [EmailService],
    exports: [EmailService],
})
export class EmailModule {}
```

## email.service.ts

```typescript
import { Injectable } from '@nestjs/common';
import { MailerService } from '@nestjs-modules/mailer';

@Injectable()
export class EmailService {
    constructor(private readonly mailerService: MailerService) {}

    async sendConfirmationEmail(to: string, prenom: string, token: string): Promise<void> {
        const confirmUrl = `${process.env.FRONTEND_URL}/confirmer-email?token=${token}`;

        await this.mailerService.sendMail({
            to,
            subject: "Confirme ton inscription — HomeCycl'Home",
            text: `Bonjour ${prenom},\n\nClique sur ce lien pour confirmer ton compte :\n${confirmUrl}\n\nCe lien expire dans 48h.`,
        });
    }
}
```

## Outil de test local — Mailpit

Mailpit est un faux serveur SMTP local. Il intercepte tous les emails envoyés par le backend sans les transmettre à de vrais destinataires.

```bash
brew install mailpit
mailpit
# SMTP → port 1025
# Interface web → http://localhost:8025
```

---

## Variables d'environnement

```
MAIL_HOST=localhost
MAIL_PORT=1025
MAIL_USER=
MAIL_PASS=
MAIL_FROM=noreply@homecyclhome.fr
FRONTEND_URL=http://localhost:5173
```

`MAIL_USER` et `MAIL_PASS` sont vides — Mailpit n'a pas besoin d'authentification en local.
