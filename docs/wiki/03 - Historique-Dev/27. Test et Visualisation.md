## Outils utilisés

| Outil | Usage | Accès |
|---|---|---|
| **Insomnia** (ou Postman) | Envoyer des requêtes HTTP aux endpoints | — |
| **Mailpit** | Intercepter les emails de confirmation en dev | `http://localhost:8025` |

## Lancer les outils

```bash
# Dans un terminal dédié — intercepteur email local
mailpit

# Dans un autre terminal — visualiseur de base de données
cd Backend
npx prisma studio
```

## Flux de test complet

### 1. Inscription

```
POST http://localhost:3000/auth/register
Content-Type: application/json

{
  "nom": "Biot",
  "prenom": "Yannick",
  "email": "yannick@test.fr",
  "password": "motdepasse123",
  "telephone": "0612345678"
}
```

**Résultat attendu :**
- HTTP 201 + `{ "message": "Inscription réussie. Vérifie ton email..." }`
- Email visible dans Mailpit (`http://localhost:8025`)
- Dans Prisma Studio : utilisateur créé avec `is_actif = false` et `email_confirmation_token` renseigné

---

### 2. Confirmation email

Copier le token depuis Mailpit ou Prisma Studio.

```
GET http://localhost:3000/auth/confirm-email?token=LE_TOKEN
```

**Résultat attendu :**
- HTTP 200 + `{ "message": "Email confirmé. Tu peux maintenant te connecter." }`
- Dans Prisma Studio : `is_actif = true`, `email_confirmation_token = null`, `token_expires_at = null`

---

### 3. Connexion avant confirmation (cas d'erreur)

```
POST http://localhost:3000/auth/login
Content-Type: application/json

{
  "email": "yannick@test.fr",
  "password": "motdepasse123"
}
```

**Si compte non confirmé :** HTTP 403 `"Confirme ton email avant de te connecter."`

---

### 4. Connexion après confirmation

Même requête qu'au point 3.

**Résultat attendu :**
- HTTP 200 + `{ "userId": "...", "role": "client" }`
- Cookies `access_token` et `refresh_token` posés dans la réponse (visibles dans Insomnia / onglet Cookies)
- Dans Prisma Studio : `refresh_token_hash` renseigné, `date_dernier_login` mis à jour

---

### 5. Déconnexion

```
POST http://localhost:3000/auth/logout
(avec le cookie access_token dans la requête)
```

**Résultat attendu :**
- HTTP 200 + `{ "message": "Déconnecté." }`
- Cookies effacés
- Dans Prisma Studio : `refresh_token_hash = null`
