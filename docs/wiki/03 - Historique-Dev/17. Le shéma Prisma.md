# 17. Le Schéma Prisma

**Sprint :** 1 — Authentification  
**Fichier :** `Backend/prisma/schema.prisma`  
**Statut :** ✅ Terminé

---

## Concept

Prisma est un ORM (Object-Relational Mapper). Son rôle : faire le pont entre le code TypeScript et PostgreSQL. Au lieu d'écrire du SQL brut, on décrit la base de données dans `schema.prisma` et Prisma génère automatiquement un client TypeScript fortement typé.

Trois concepts clés :
- **Le schéma** (`schema.prisma`) → source de vérité de la structure de données
- **Les migrations** → fichiers SQL générés automatiquement à partir du schéma
- **Le client généré** → code TypeScript auto-généré importé dans les services

## Localisation

Le fichier est à `Backend/prisma/schema.prisma` (racine du Backend, pas dans `src/`). C'est une convention Prisma CLI — il s'exécute depuis la racine du projet, indépendamment de NestJS. Le `prisma.config.ts` à la racine pointe vers ce dossier.

> ⚠️ `prisma.config.ts` doit être **exclu** de la compilation NestJS dans `tsconfig.build.json` pour éviter des conflits de compilation.

## Stratégie

On ne déclare que les tables nécessaires au sprint en cours. Les autres entités (`Intervention`, `Creneau`, etc.) seront ajoutées progressivement — chaque ajout génère une nouvelle migration.

## Modèle Utilisateur

```prisma
generator client {
  provider = "prisma-client-js"
  output   = "../generated/prisma"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

enum Role {
  client
  technicien
  admin
}

model Utilisateur {
  id                       String    @id @default(uuid())
  nom                      String
  prenom                   String
  email                    String    @unique
  password_hash            String
  telephone                String
  role                     Role      @default(client)
  is_actif                 Boolean   @default(false)
  email_confirmation_token String?   @unique
  token_expires_at         DateTime?
  refresh_token_hash       String?
  date_creation            DateTime  @default(now())
  date_maj                 DateTime  @updatedAt
  date_dernier_login       DateTime?

  @@map("Utilisateurs")
}
```

### Champs notables

| Champ | Explication |
|---|---|
| `@id @default(uuid())` | Clé primaire UUID — pas d'entier auto-incrémenté |
| `is_actif = false` | Compte inactif jusqu'à confirmation email |
| `email_confirmation_token` | Token aléatoire envoyé par email, effacé après confirmation |
| `token_expires_at` | Expiration du lien de confirmation (48h) |
| `refresh_token_hash` | Hash du refresh token — jamais stocké en clair |
| `@updatedAt` | Mis à jour automatiquement par Prisma à chaque modification |
| `date_dernier_login` | Nullable — mis à jour manuellement lors du login |
| `@@map("Utilisateurs")` | Nom de la table SQL en français |

## Commandes utiles

```bash
# Créer une migration
npx prisma migrate dev --name nom_de_la_migration

# Visualiser la base en local
npx prisma studio
# → ouvre http://localhost:5555
```

Dans `Backend/.env` :
```
DATABASE_URL=postgresql://user@localhost:5432/nomdelabase
```
