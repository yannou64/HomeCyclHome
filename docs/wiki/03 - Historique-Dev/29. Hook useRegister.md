Même pattern que `useLogin`. Crée **`Frontend/src/features/auth/hooks/useRegister.ts`** :

```typescript
import { useState } from 'react';
import axios from 'axios';
import { authService } from '../services/authService';
import type { RegisterPayload } from '../types/auth.types';

export function useRegister() {
    const [isLoading, setIsLoading] = useState(false);
    const [error, setError] = useState<string | null>(null);
    const [isSuccess, setIsSuccess] = useState(false);

    async function handleRegister(payload: RegisterPayload) {
        setIsLoading(true);
        setError(null);
        try {
            await authService.register(payload);
            setIsSuccess(true);
        } catch (e) {
            if (axios.isAxiosError(e) && e.response?.status === 409) {
                setError('Cet email est déjà utilisé.');
            } else {
                setError('Une erreur est survenue. Réessaie.');
            }
        } finally {
            setIsLoading(false);
        }
    }

    return { handleRegister, isLoading, error, isSuccess };
}
```

> ⚠️ **Mise à jour :** l'import `register` individuel a été remplacé par l'objet `authService`
> (voir la note dans [[8. Le hook useLogin]]). L'import `useNavigate` d'origine a également été
> retiré — ce hook ne redirige jamais après inscription (voir plus bas), il n'en avait pas besoin.

Trois états distincts :

- `isLoading` — pendant l'appel API
- `error` — message d'erreur à afficher dans le formulaire
- `isSuccess` — bascule l'affichage du formulaire vers un message de confirmation

Pas de redirection après l'inscription — on reste sur la page et on affiche "Vérifie ton email".
