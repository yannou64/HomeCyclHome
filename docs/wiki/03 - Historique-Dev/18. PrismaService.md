### Qu'est-ce que c'est ?

NestJS fonctionne avec un système d'**injection de dépendances**. Au lieu d'instancier directement `new PrismaClient()` dans chaque service, on crée une classe `PrismaService` injectable — NestJS gère son cycle de vie et la partage entre tous les modules qui en ont besoin.

C'est le pont entre le client Prisma généré et le monde NestJS.

### Ce qu'il faut créer

**`Backend/src/shared/prisma/prisma.service.ts`** :

```typescript
import { Injectable, OnModuleInit } from '@nestjs/common';
import { PrismaClient } from '../../../generated/prisma';

@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit {
    async onModuleInit(): Promise<void> {
        await this.$connect();
    }
}
```

**`OnModuleInit`** est une interface NestJS : quand le module démarre, NestJS appelle automatiquement `onModuleInit()`. On en profite pour ouvrir la connexion à la base.

**`Backend/src/shared/database/database.module.ts`** :

```typescript
import { Global, Module } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';

@Global()
@Module({
    providers: [PrismaService],
    exports: [PrismaService],
})
export class DatabaseModule {}
```

**`@Global()`** signifie que ce module, une fois importé dans `AppModule`, rend `PrismaService` disponible partout dans l'application sans avoir à le ré-importer dans chaque module métier. On l'importe une seule fois, il est disponible partout.
