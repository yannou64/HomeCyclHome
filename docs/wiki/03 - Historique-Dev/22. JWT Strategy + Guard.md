## Concept

NestJS utilise **Passport.js** comme couche d'authentification :

- Une **Strategy** définit *comment* vérifier une identité (lire un JWT depuis un cookie et le valider)
- Un **Guard** est un gardien placé devant un endpoint — il appelle la strategy et bloque la requête si elle échoue

---

## jwt.strategy.ts

```typescript
import { Injectable } from '@nestjs/common';
import { PassportStrategy } from '@nestjs/passport';
import { ExtractJwt, Strategy } from 'passport-jwt';
import { Request } from 'express';

@Injectable()
export class JwtStrategy extends PassportStrategy(Strategy, 'jwt') {
    constructor() {
        super({
            jwtFromRequest: ExtractJwt.fromExtractors([
                (req: Request): string | null => {
                    const cookies = req.cookies as Record<string, string | undefined>;
                    return cookies?.access_token ?? null;
                },
            ]),
            secretOrKey: process.env.JWT_ACCESS_SECRET as string,
        });
    }

    validate(payload: { sub: string; role: string }) {
        return { userId: payload.sub, role: payload.role };
    }
}
```

**Points notables :**
- `jwtFromRequest` lit le token dans `req.cookies.access_token` (cookie HttpOnly posé au login)
- `cookies as Record<string, string | undefined>` — cast nécessaire car ESLint (`no-unsafe-member-access`) interdit l'accès à des propriétés sur un type `any`
- `secretOrKey as string` — nécessaire car `process.env` retourne `string | undefined` en mode strict
- `validate()` retourne `{ userId, role }` qui est injecté dans `req.user` sur les routes protégées

## jwt-auth.guard.ts

```typescript
import { Injectable } from '@nestjs/common';
import { AuthGuard } from '@nestjs/passport';

@Injectable()
export class JwtAuthGuard extends AuthGuard('jwt') {}
```

Intentionnellement minimal — `AuthGuard('jwt')` appelle automatiquement la strategy `'jwt'` définie ci-dessus.

**Usage sur un endpoint :**
```typescript
@UseGuards(JwtAuthGuard)
@Post('logout')
logout(@Req() req: Request) {
    const user = req.user as { userId: string };
    // ...
}
```
